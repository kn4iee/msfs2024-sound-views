# MSFS Sound Views

Custom cabin camera views for Microsoft Flight Simulator 2024, picked for how they sound.
They cover the PMDG 777 and 737, the Fenix A319, A320 and A321, the FlyByWire A32NX and the iFly 737 MAX 8.

## Guides

Read the guides online:

- [1 - What each view is](https://kn4iee.github.io/msfs2024-sound-views/1%20-%20What%20each%20view%20is.html): what each key shows, how to install, and every aircraft's views. Start here.
- [2 - How to build sound views from scratch](https://kn4iee.github.io/msfs2024-sound-views/2%20-%20How%20to%20build%20sound%20views%20from%20scratch.html): the full method, for building views like these.
- [3 - Changelog](https://kn4iee.github.io/msfs2024-sound-views/3%20-%20Changelog.html): what changed since the first version, and why.

The same guides are in the download as HTML files, so they also open offline.

## Download

[Download everything as a ZIP file](https://github.com/kn4iee/msfs2024-sound-views/archive/refs/heads/main.zip).

## What's inside

- **Views**: the 59 view files. To install them, copy the folders inside Views into
  `%APPDATA%\Microsoft Flight Simulator 2024\SimObjects\Airplanes` (Steam version of the sim).
- **1 - What each view is.html**, **2 - How to build sound views from scratch.html** and **3 - Changelog.html**: the three guides above.
- **Reference scripts**: the Python scripts used to build the views.
