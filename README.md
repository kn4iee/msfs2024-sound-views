# MSFS Sound Views

Custom cabin camera views for Microsoft Flight Simulator 2024, picked for how they sound.
They cover the PMDG 777 and 737 (including the 737-600), the Fenix A319, A320 and A321, the FlyByWire A32NX,
the iFly 737 MAX 8 and the TFDi MD-11 and MD-11F.

## Guides

The guides are HTML files in this repo. Download the ZIP below, unzip it, and open them in any web browser:

- [1 - What each view is.html](1%20-%20What%20each%20view%20is.html): what each key shows, how to install, and every aircraft's views. Start here.
- [2 - How to build sound views from scratch.html](2%20-%20How%20to%20build%20sound%20views%20from%20scratch.html): the full method, for building views like these.
- [3 - Changelog.html](3%20-%20Changelog.html): what changed since the first version, and why.

## Download

[Download everything as a ZIP file](https://github.com/kn4iee/msfs2024-sound-views/archive/refs/heads/main.zip).

## What's inside

- **Views**: the 69 view files. To install them, copy the folders inside Views into
  `%APPDATA%\Microsoft Flight Simulator 2024\SimObjects\Airplanes` (Steam version of the sim).
- **1 - What each view is.html**, **2 - How to build sound views from scratch.html** and **3 - Changelog.html**: the three guides above.
- **Reference scripts**: the Python scripts used to build the views.
