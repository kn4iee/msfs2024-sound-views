# MSFS Sound Views

Custom cabin camera views for Microsoft Flight Simulator 2024, picked for how they sound.
They cover the PMDG 777 and 737 (including the 737-600), the Fenix A319, A320 and A321, the FlyByWire A32NX,
the iFly 737 MAX 8, the TFDi MD-11 and MD-11F and the BlueBird 757-200.

## Guides

The guides are Markdown files, so GitHub shows them as formatted pages. In the download they open in any text editor.

- [1 - What each view is](1%20-%20What%20each%20view%20is.md): what each key shows, how to install, and every aircraft's views. Start here.
- [2 - How to build sound views from scratch](2%20-%20How%20to%20build%20sound%20views%20from%20scratch.md): the full method, for building views like these.
- [3 - Changelog](3%20-%20Changelog.md): what changed since the first version, and why.

## Download

[Download everything as a ZIP file](https://github.com/kn4iee/msfs2024-sound-views/archive/refs/heads/main.zip).

## What's inside

- **Views**: the 79 view files. To install them, copy the folders inside Views into
  `%APPDATA%\Microsoft Flight Simulator 2024\SimObjects\Airplanes` (Steam version of the sim).
- **1 - What each view is.md**, **2 - How to build sound views from scratch.md** and **3 - Changelog.md**: the three guides above.
- **Reference scripts**: the Python scripts used to build the views.
